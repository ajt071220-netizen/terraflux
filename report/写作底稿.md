## 1. Introduction 素材包

### 1.1 游戏规则（精确版，供压缩改写）

- **棋盘**：25×25 柱阵（训练与评测还覆盖 15–27 奇数尺寸）。每格地形四态：
  正常（高度 0）、隆起（+1）、下陷（−1）、填平（不可进入）。
- **双方**：白＝逃离者（escapee），黑＝追捕者（pursuer）。棋子高度等于所在柱的高度。
- **行动**：轮流执行，每手移至 8 邻格之一；不可越界、不可进入填平格、
  不可进入对方占据格。
- **地形改写（核心机制）**：每次落子后，按当前相位改写**落点周围**：
  - 十字相位：北邻隆起、南邻下陷、东西两邻填平；
  - 斜向相位：东北、西北隆起，东南、西南下陷，不填平。
  - 相位按**执子方各自的手数**交替：某方第 1、3、5… 手为十字相位，
    第 2、4、6… 手为斜向相位。
- **胜负判定**（每次落子后立即裁决）：
  - 若双方切比雪夫距离＝1 且 黑高＞白高 → 黑胜（capture）；
  - 若白方落在南边线（最后一行）：不同时满足抓捕条件 → 白胜（escape）；
    同时满足抓捕条件 → **平局**（border-capture，逃脱与抓捕同一瞬间）；
  - 同一局面（含地形快照）出现三次 → 和棋；
  - 训练环境中单局超过 400 手判平（保险丝，网页端无此上限）。
- **标准开局（duel 布局）**：黑置中央（13,13），白置其正北（10,13），
  间距 3（中间隔两格），黑先行。该配置经 RL 自对弈实测白胜率 46%，
  为全部受测配置中最接近均衡者。

### 1.2 公平性问题的由来（引言故事线）

1. 游戏发明后，人工对局与批量模拟均提示：部分规则组合下一方存在碾压性优势；
2. 但"是否公平"无法人工推演——地形每步被改写，位置与高度强耦合，
   状态空间庞大，人类直觉在动态地形上失效；
3. 于是将规则全面参数化（抓捕条件 gt/gte、胜利边集合、相位模式、先手、
   开局间距），先用启发式批量模拟粗扫，再用 RL 收敛策略精测——
   报告即围绕这条"从规则调试到科学测量"的线索展开。

## 2. Methods 素材包

### 2.1 系统（双实现互验）

- 规则引擎以 JavaScript 实现（驱动 Three.js 3D 可玩前端），
  再逐行移植至 Python（驱动训练与批量评测）；两实现行为逐条对稿，
  保证"网页上玩到的规则"与"AI 训练的规则"完全一致。
- 前端另集成首访教学卡与自动演示对局（双语解说），无需后端即可运行。

### 2.2 三类智能体

- **启发式（弱策略代表）**：1 层前瞻＋手工评估函数＋少量噪声。
  白方评估项：趋近胜利边（×4）、与黑保持距离（×2，距离按 6 封顶）、
  自身站高（×6）并压低黑方（×4）、一步制胜（+500）、相邻而无高度优势（−80）；
  黑方评估项：逼近白方（×6）、站高压低、阻止白方近边（×2）、一步可擒（+500）。
- **LLM**：OpenAI 兼容接口（开发使用 Qwen3.8-Max）。提示词含规则、当前局面、
  每个合法着法的后果预览；引擎对 LLM 所选着法做 2 层前瞻安全审查，
  危险着法被否决并回退至启发式选择（propose-and-veto 混合架构）。
- **PPO（主角）**：见 2.3。

### 2.3 PPO 训练配置（与 train_ppo.py 完全一致）

- 算法：MaskablePPO（sb3-contrib），非法动作以掩码屏蔽；
- 观测：board 25×25×4 地形 one-hot；pieces 25×25×2 双方位置；
  meta 8 维（双方柱高、双方切比雪夫距离、目标边距离、相位 one-hot×3、执子方）；
- 动作：Discrete(9)＝8 个方向＋停步；
- 网络：BoardMLP 特征提取＋MLP 隐藏层 [256, 256]；
- 超参：学习率 3e-4，n_steps 2048，batch_size 256；
- 奖励：终局胜 +1 / 负 −1 / 平 0（**稀疏**）；实验组另加每步 −0.002 步罚；
- 自我对弈：对手池＝65% 启发式＋35% 自身历史快照（最近 5 个）；
  主训练规模 50 万步（实测吞吐约 500 步/秒）。

### 2.4 评估协议

- 自对弈平衡率：同一模型交替执白执黑，每条件 200–300 局，报 95% 置信区间；
- 跨模型强度：两两循环赛、互换颜色，每对 200 局；
- **方法论纪律**：跨模型比较一律采用循环赛直接对局；
  训练日志中的滚动胜率仅用于观察学习进度，不可用于横向强度比较
  （§3.1 将证明二者可给出相反结论）。

## 3. Results 素材包

### 3.1 奖励整形消融（全部数字）

- 设置：两组 MaskablePPO 从零训练，唯一变量为步罚（shaped −0.002 vs sparse 0），
  各 50 万步，duel gap3 黑先；
- 达到滚动胜率 55%：shaped **59k 步** vs sparse 73k 步（慢 24%）；
  达到 65%：65k vs 77k（慢 18%）；
- 末段日志胜率：0.716 vs 0.709——**看似持平**；
- 循环赛直接对局：shaped **66.0%** vs sparse 14.5%（平 19.5%）——**实为碾压**；
- 末段平均局长：28.8 vs 29.2 步（无显著差异）；
- 解释：日志胜率是"各自对自身快照池"的相对值，池强度不同则不可比；
  sparse 组学到的是"对弱对手苟活"的策略风格，遇强即崩；
  步罚的价值不在压缩局长（游戏天然约 30 步分胜负），而在塑造进取型策略。

### 3.2 训练动态解剖（全部数字）

- 数据来源：主训练 50 万步、rollout 级日志 245 个采样点；
- 三阶段：早期（2k–165k）胜率 0.419／熵 −1.119／局长 23.1；
  中期（167k–331k）0.672／−0.850／25.8；后期（333k–501k）0.712／−0.757／20.0；
- 中期（150k–400k）滚动胜率持续宽幅震荡（约 0.4–0.7 区间拉锯）：
  学习方与对手池（自身快照）同步变强所致，属自我对弈固有动力学，非训练故障；
- 佐证稳定性：全程无 KL 尖峰（阈值 0.15）；仅 94k、104k 两次熵跳变，
  均与新快照注入对手池的时刻吻合（数据分布瞬变，良性适应）；
- 值函数解释方差由 0.2 升至 0.8 但从未饱和：非平稳环境中价值函数持续追标。

### 3.3 公平性的强度条件化（核心，全部数字）

- 强度梯度（duel gap3 黑先，自对弈白胜率）：
  启发式互弈 **0%**（平均局长 10 步）→ PPO sparse **20%**（±5.6%，59 步）
  → PPO shaped **34%**（±6.5%，75 步）→ PPO 主模型 **46%**（±6.9%，54 步）。
  严格单调，向 50% 收敛；
- 强度排名依据（循环赛矩阵，行对列胜率，平折算 0.5）：
  shaped 66.0 : 14.5 sparse；主模型 53.5 : 31.5 shaped；主模型 43.0 : 37.5 sparse；
- 尺寸对照（启发式互弈，每尺寸 300 局）：15×15 至 27×27，黑先时白胜率
  恒为 ≈0%（最高 0.3%），白先时 11.7%–18.0%——尺寸不构成公平性变量；
- **机制解释（准确表述，务必照此写）**：
  启发式白方的评估函数**确实含有**间距项，但其权重（×2、距离封顶 6）
  远低于趋边驱动（×4）——实战中冲边压倒避敌，白方事实上"不会逃"，
  黑方直线追击平均 10 步完成捕捉。PPO 在与升级对手池的对抗中自行习得
  保持间距、借助地形起伏阻断追捕路线的技术；逃逸技术越成熟，开局越显公平。
  中间档位（20%、34%）即"逃逸技术不完全"的过渡形态；
- 核心论点：规则公平性不能脱离玩家强度定义；"平衡开局"是强度依赖的
  连续谱而非布尔属性；以 RL 收敛策略做公平性基准，是人工试玩无法替代的方法论。

## 4. Discussion 素材包

### 4.1 方法论亮点（可各用一句写进讨论）

1. 自我对弈日志胜率的"记账错觉"：0.716≈0.709 的表象与 66:14.5 的实情；
2. 对手池共进化的震荡是特征而非缺陷，且可用熵/KL/快照注入时刻加以鉴别；
3. 公平性＝强度条件化的谱——本报告提出的操作化定义框架。

### 4.2 局限性（诚实声明）

1. 消融实验为单随机种子；±6% 量级的差异需多种子复核；
2. "弱策略"由启发式一类代表支撑，外推至"一切弱策略"需谨慎；
3. 强策略下的尺寸扫描需逐尺寸独立训练模型，受算力所限留作后续工作；
4. 平衡率测量样本 200–300 局，95% 置信区间约 ±6%。

### 4.3 未来工作（备选，挑 1–2 条）

- 多种子消融复核；强策略条件下的尺寸×公平性相变扫描；
- 将 LLM 智能体作为"第三类策略强度样本"纳入强度—公平性曲线；
- 引入课程学习（curriculum）进一步压缩稀疏奖励下的早期训练成本。

## 5.5 §2.0 设计哲学素材包（价值镜像检验）

### 原理

追逃结构里藏着一条定律：**凡是影响"移动效率"的地形效果天然偏袒白方，
凡是影响"行动能力"的效果天然偏袒黑方**。因为白的胜利条件是位移
（抵达边线），黑的胜利条件是控制（锁住白）。

据此得到**价值镜像检验**：地形机制要公平，它对逃方的价值与对追方的
价值必须互为镜像（一方能用，另一方也能用；一方受害，另一方也可能受害）。

### 被淘汰的设计（单边武器清单，报告可点名）

| 机制 | 挂科原因 |
|---|---|
| 传送格 / 加速格 | 帮助位移 → 纯偏白（眨眼到边线，黑永远追不上） |
| 冻结格 / 泥沼格（停一手） | 剥夺行动 → 纯偏黑（追逃中被冻＝直接死，黑从不需要逃） |
| 单向门 | 位移效率的不对称操纵 → 单边受益 |

### 通过检验的现存机制（唯二）

- **高度**（隆起/下陷）：黑需要它抓捕、白需要它防抓——需求镜像 ✓
- **通行性**（填平）：堵路是双刃剑——能封白的逃路，也可能挡黑自己的
  追击路线 ✓

### 候选机制（自称过检、待 RL 实测，写入未来工作）

1. 更高档位（允许 ±2 柱）——高度军备竞赛升级，镜像不变；
2. 退潮格（填平数手后自动复原）——通行性加时间维度，双方都要算潮汐；
3. 地形自主演化（下陷格无人干预则缓慢回弹）——作用于"地"本身，无偏向；
4. 长程共震（落子影响整列而非仅邻格）——空间模式变化，对双方同等。

### 报告可用句式

- "The terrain vocabulary is small by design: any effect that touches
  movement efficiency is a one-sided weapon in a pursuit game —
  teleportation favors the runner, freezing favors the hunter — so both
  were rejected. Only height and passability pass what I call the
  mirror-value test."
- 未来工作句："Each candidate mechanic claims to pass the mirror-value
  test, but claims are cheap: every one of them must be re-measured by the
  RL referee pipeline before it is allowed into the ruleset."
